# Sistema WebAR — UNAMA

## Objetivo

Este projeto tem como objetivo desenvolver uma aplicação de **Realidade Aumentada (WebAR)** para a UNAMA, permitindo que usuários utilizem a câmera do celular para reconhecer imagens e acessar conteúdos digitais interativos relacionados à instituição.

A partir do reconhecimento de uma imagem, o sistema poderá apresentar diferentes tipos de conteúdo, como **modelos 3D, áudios, vídeos e links para o Instagram da UNAMA**.

A solução também busca utilizar a realidade aumentada como recurso para **divulgação da instituição e identificação de ambientes, como salas da UNAMA**, proporcionando uma experiência interativa e acessível diretamente pelo navegador, sem a necessidade de instalar um aplicativo.
