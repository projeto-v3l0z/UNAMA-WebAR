# Assets

Pasta destinada aos arquivos estáticos utilizados no sistema WebAR.

```text
assets/
├── images/   # Imagens e targets
├── models/   # Modelos 3D (.glb)
├── audios/   # Áudios (.mp3)
├── videos/   # Vídeos (.mp4)
└── targets/  # Arquivos do MindAR (.mind)
```

Os arquivos devem utilizar nomes simples e padronizados, como:

```text
personagem-unama.glb
sala-101.mp3
fachada-unama.jpg
```
